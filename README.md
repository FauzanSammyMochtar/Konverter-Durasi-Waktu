# Konverter Durasi Waktu

## Deskripsi
Proyek untuk mengkonversi detik ke format waktu.

## Persyaratan
* C Compiler (Seperti GCC/Clang)

## Cara Menggunakan
1. Unduh atau clone repositori ini:
git clone https://github.com/FauzanSammyMochtar/Konverter-Durasi-Waktu.git

2. Masuk ke folder proyek:
cd Konverter-Durasi-Waktu

3. Compile program:
clang konverter_durasi_waktu.c -o konverter_durasi_waktu

4. Jalankan program:
./konverter_durasi_waktu
